## 🚀 Featured Project

### 📄 ResumeIQ

**Intelligent ATS Resume Screening**

</div>

ResumeIQ is a resume screening project that analyzes resumes against job descriptions using string-matching algorithms.

### What it does

* 📁 Resume file upload
* 📝 Resume text input
* 🔎 Job description analysis
* 🔗 Keyword matching
* 📊 Word frequency analysis
* ⚡ Algorithmic comparison

### Algorithms

```text
KMP String Matching
        +
Rabin–Karp String Matching
        ↓
Keyword Matching & Analysis
```
